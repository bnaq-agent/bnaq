常见问题

没有 Agent ID 可以买吗？

不可以。打新合约会校验调用地址在 SPACE ID Agent ID 注册表中的持有状态，没有 Agent ID 的地址调用 buy 会被合约直接拒绝，页面也无法绕过。

买错了可以退吗？

不可以。付款成功后代币即时到账，链上交易不可撤销，下单前请确认份数和地址。

BNAQ 之后能在哪里交易？

目前没有任何交易池，也没有上线承诺。是否在售罄后建池由项目方另行决定并公布，在此之前请按「可能长期无法变现」来评估。

这是币安官方的项目吗？

不是。BNAQ 是社区 Meme 项目，与币安官方无关；「代表币安安全」只是名字的谐音梗（BN + 安全拼音 AQ）。
